# bp
Blood Pressure Calculator
ASP.Net Core

## Load tests

Install [k6](https://grafana.com/docs/k6/latest/set-up/install-k6/), then start the web app and run:

```sh
npm run loadtest
```

The test runs four category-specific scenarios concurrently, ramping up to 10 virtual users total, holding that load for one minute, and ramping down. Set `MAX_VUS` to an integer of at least 4; k6 distributes the total peak VUs across the scenarios. Each scenario loads the calculator page and submits its reading, including the Razor Pages antiforgery token. A failed threshold aborts the run after its 10-second evaluation delay.

Set `BASE_URL` to target a different running instance (default: `http://localhost:5000`) and `MAX_VUS` to change the peak virtual users. For example, in PowerShell:

```powershell
$env:BASE_URL = "https://your-app.example.com"
$env:MAX_VUS = "20"
npm run loadtest
```

### Stream results to Grafana Cloud k6

The GitHub Actions workflow runs the same test on the GitHub-hosted runner and streams its results to Grafana Cloud k6. Add these repository secrets in **Settings > Secrets and variables > Actions**:

- `K6_CLOUD_TOKEN`: a Grafana Cloud k6 API token.
- `K6_CLOUD_STACK_ID`: the ID of your Grafana Cloud stack.

To stream results locally, set those environment variables and run:

```sh
npm run loadtest:cloud
```

This uses local execution, so the load is generated by the machine running k6; the test results are uploaded to Grafana Cloud. Run load tests only against systems you own or are authorized to test.
